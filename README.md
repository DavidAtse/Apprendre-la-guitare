# 🎸 StringMaster - Apprendre la Guitare

Une landing page moderne et responsive pour une plateforme d'apprentissage de la guitare en ligne, construite en **HTML5, CSS3 et JavaScript pur**.

<!-- Remplace ou active le lien une fois GitHub Pages configuré -->
🌐 **Démo en ligne :** [Voir le site](https://davidatse.github.io/Apprendre-la-guitare/)

---

## ✨ Fonctionnalités

- 📱 **Design responsive** : Adapté aux ordinateurs, tablettes et smartphones avec un menu burger interactif.
- 🎼 **Présentation des fonctionnalités** : Visual Fretboard Trainer, Interactive Tab Player, suivi de progression, etc.
- 💳 **Section Tarifs & Abonnements** : Plans mensuels et annuels pour les apprenants.
- 👨‍🏫 **Instructeurs & Témoignages** : Présentation des professeurs certifiés et avis des étudiants.

---

## 🛠️ Technologies utilisées

| Technologie | Rôle |
|---|---|
| **HTML5** | Structure sémantique de la page |
| **CSS3** | Mise en page, styles modernes, Flexbox/Grid et responsive design |
| **JavaScript (ES6)** | Gestion de l'interactivité (menu mobile hamburger) |

## 🚀 Lancer le projet localement

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/DavidAtse/Apprendre-la-guitare.git
   ```

2. **Ouvrir le projet :**
   Ouvre simplement `index.html` dans ton navigateur ou utilise l'extension **Live Server** sur VS Code.
